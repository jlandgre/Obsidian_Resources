This Github repo is a sync of a personal Obsidian folder to publicly share raw notes and reflections about tech and other topics and to share clipped links to articles, tweets etc.  Because Obsidian uses markdown, its notes render as formatted when viewed on Github, so it's a way to put things out there in a nice format for sharing with others.
